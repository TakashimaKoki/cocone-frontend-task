# ココネ　フロントエンド課題
## 〜郵便番号住所検索 SPA〜

## 概要

郵便番号を入力して住所を検索できる SPA です。
zipcloud の郵便番号検索 API を利用し、検索結果として以下を表示します。

- 郵便番号
- 住所
- 住所（カタカナ）

また、検索履歴を画面下部に表示し、3件ごとにカルーセル形式で確認できるようにしています。

## 使用技術

- TypeScript
- HTML
- SCSS
- Vite
- Embla Carousel
- zipcloud 郵便番号検索 API

## 動作環境

- Node.js: 24.15.0
- npm: 11.12.1

## セットアップ手順

1. リポジトリをクローンまたはダウンロードします。
2. プロジェクトのルートディレクトリへ移動します。
3. 依存パッケージをインストールします。

```bash
npm install
```

## 開発サーバ起動手順

以下のコマンドでローカル開発サーバを起動します。

```bash
npm run dev
```

起動後、ターミナルに表示されるローカル URL をブラウザで開いてください。

## ビルド手順

本番用ビルドは以下のコマンドで実行できます。

```bash
npm run build
```

## 実装した主な機能

### 1. 郵便番号検索

- 郵便番号入力欄に `0000000` または `000-0000` の形式で入力可能
- ハイフンあり／なしの両方に対応
- 検索ボタン押下時に zipcloud API を呼び出して住所を取得

### 2. バリデーション

- 入力欄が空の場合は検索ボタンを無効化
- 8文字を超える入力を制限
- 半角数字とハイフン以外が入力された場合はエラー表示
- 郵便番号形式が不正な場合はエラー表示
- 存在しない郵便番号の場合は専用エラー表示
- その他通信エラーの場合は汎用エラー表示

### 3. 検索結果表示

- 検索結果として以下を表示
  - 郵便番号
  - 住所
  - 住所（カタカナ）
- 検索結果が複数件ある場合は全件表示

### 4. 検索履歴表示

- 正常検索時のみ検索履歴を追加
- 検索履歴をカード形式で表示
- 履歴は新しいものを先頭に追加
- 履歴カードをクリックすると、当時の検索結果を展開表示

### 5. カルーセル表示

- 検索履歴は3件ごとに1ページとして表示
- 戻る／進むボタンに対応
- ページネーションに対応
- ドラッグ／スワイプ操作に対応
- ループはしない
- 最初の位置では戻るボタンを非活性化
- 最後の位置では進むボタンを非活性化

### 6. レスポンシブ対応

- モバイルファーストで実装
- 768px を breakpoint としてレイアウトを切り替え
- PC では履歴カードを3件横並び
- モバイルでは履歴カードを縦並び表示

## 工夫した点

1. バリデーション処理、API 通信処理、描画処理を分離し、`main.ts` に責務が集中しすぎないようにしました。
2. 郵便番号の整形処理を切り出し、API 呼び出し時にはハイフンなし7桁へ正規化するようにしました。
3. エラーメッセージを定数として管理し、文言の重複やタイポを防ぎやすくしました。
4. 履歴カードから当時の検索結果を展開できるようにし、単なるログ表示ではなく再確認しやすい UI を意識しました。
5. カルーセル部分はページ分割とボタン制御を意識し、仕様どおりにループしない実装にしました。
